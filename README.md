# VetCare Management Web

Frontend web application for the VetCare Management platform.

## Technologies

- React
- TypeScript
- Vite
- React Router
- npm
- ESLint
- Prettier

## Getting Started

```bash
npm install
npm run dev
```

The application starts on `http://localhost:5173` by default.

## Main Commands

```bash
npm run dev
npm run build
npm run lint
npm run format
npm run preview
```
